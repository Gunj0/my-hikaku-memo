# 画面仕様設計

## 1. 文書の目的

本書は、各ステップ画面の表示項目、入力項目、操作、表示条件、レスポンシブ差分を定義する。

## 2. 共通画面仕様

### 2.1 ヘッダー

- アプリ名を表示する。
- アプリ名の上に小さなメタラベルを表示できる。
- ログイン状態を表示する。
- 保存ボタンを表示する。
- 保存済みメモ一覧ボタンを表示する。
- ログインまたはログアウトボタンを表示する。
- リセットボタンを表示する。
- 進捗インジケータを表示する。
- 進行率、重視ポイント数、候補数、保存状態を高密度に表示する。

### 2.2 共通ダイアログ

- 未ログイン時に保存系操作を行った場合はログイン案内ダイアログを表示する。
- 保存時はメモタイトル入力ダイアログを表示する。
- 保存済みメモ一覧表示時は、読込と削除操作を含む管理ダイアログを表示する。

### 2.2 メイン領域

- currentStep に応じたステップ画面を 1 つ表示する。
- デスクトップでは補助的なサイド情報領域を併設できる。

### 2.3 フッター

- 戻るボタンを表示する。
- 現在ステップ番号と総ステップ数を表示する。
- 次へ進む、または完了ボタンを表示する。

## 3. ステップ 1: カテゴリ

### 3.1 表示項目

- 見出し
- 説明文
- プリセットカテゴリボタン群
- カスタムカテゴリ入力欄
- カテゴリメモ入力欄

### 3.2 操作

- プリセットカテゴリボタン押下でカテゴリを設定する。
- カスタムカテゴリ入力でカテゴリを設定する。
- 補助ボタン押下で入力中カテゴリを確定する。
- メモ欄へ自由記述する。

### 3.3 表示ルール

- 選択中のプリセットカテゴリは強調表示する。
- カスタムカテゴリが選択されている場合のみ入力欄に値を表示する。

## 4. ステップ 2: 比較ポイント

### 4.1 表示項目

- 見出し
- 説明文
- ポイント件数、重視件数
- 初期値に戻すボタン
- 比較ポイント一覧
- 新規ポイント追加欄
- 全体メモ入力欄

### 4.2 操作

- 重視チェックの切り替え
- 重要度星評価の切り替え
- 詳細領域の開閉
- 個別メモ入力
- 比較ポイント追加
- 比較ポイント削除
- 初期値に戻す

### 4.3 表示ルール

- 重視ポイントは背景色と枠線で強調する。
- 重要度操作は重視ポイントのみ有効とする。
- モバイルでは詳細展開時に大きめの星操作を表示する。

## 5. ステップ 3: 候補

### 5.1 表示項目

- 見出し
- 説明文
- 候補追加欄
- 空状態表示または候補一覧
- 全体メモ入力欄

### 5.2 操作

- 候補製品追加
- 候補製品削除
- 候補ごとのメモ入力
- 全体メモ入力

### 5.3 表示ルール

- 候補がない場合はアイコン付き空状態を表示する。
- 候補がある場合はカード形式で一覧表示する。
- 一覧には表示順の連番を表示する。

## 6. ステップ 4: 評価入力

### 6.1 表示項目

- 見出し
- 説明文
- 条件未達時の案内文、または評価入力 UI

### 6.2 モバイル表示

- 製品単位のカードを表示する。
- カード内に各重視ポイント名、重要度、星入力、メモ欄を表示する。

### 6.3 デスクトップ表示

- 比較ポイントを行、候補製品を列とする表を表示する。
- 各セルに星入力とメモ欄を表示する。

### 6.4 操作

- 星アイコン押下で評価点を設定する。
- メモ欄入力で対象組み合わせのメモを設定する。

### 6.5 表示ルール

- 対象は重視ポイントのみとする。
- 未入力点数は 0 点扱いとし、未選択状態の星表示とする。

## 7. ステップ 5: 集計結果

### 7.1 表示項目

- 見出し
- 説明文
- ランキングカード群
- 重み付きスコア詳細表
- 集計説明領域

### 7.2 操作

- 本ステップ自体に入力操作はない。

### 7.3 表示ルール

- 合計点降順で候補を並べる。
- 最上位かつ合計点が 0 より大きい候補を Neon Green で強調する。
- 各候補に点数、最大点に対する割合、進捗バーを表示する。
- 詳細表には「加重点」と「元の評価点×重要度」を表示する。

## 8. ステップ 6: 最終決定

### 8.1 表示項目

- 見出し
- 説明文
- 条件未達時の案内文、または候補選択 UI
- 選択済み製品の決定表示領域
- 決定理由入力欄
- 次のステップ案内

### 8.2 操作

- 候補製品の選択
- 選択解除
- 決定理由メモ入力

### 8.3 表示ルール

- 候補は集計順に並べる。
- 最上位候補は順位表示を Neon Green で強調する。
- 選択中候補は枠線とリングで明示する。
- 選択済みのときは上部に決定済み表示を出し、成功状態として Neon Green を使う。

## 9. 進捗インジケータ仕様

### 9.1 モバイル

- 横スクロール可能なボタン列とする。
- 完了済み、現在、未到達の各状態を見た目で区別する。

### 9.2 デスクトップ

- 全幅のステップ列とし、ステップ間連結線を表示する。
- 到達済みステップまでクリック可能とする。

## 10. ボタン活性仕様

- フッターの戻るボタンは currentStep > 1 のとき有効とする。
- フッターの次へボタンは各ステップの進行条件を満たすとき有効とする。
- フッターの完了ボタンは selectedProductId が存在するとき有効とする。
- ヘッダーの保存ボタンは常に表示し、未ログイン時は案内ダイアログを経由する。
- ヘッダーの保存済みメモボタンは常に表示し、未ログイン時は案内ダイアログを経由する。
- ヘッダーのリセットボタンは常に活性とする。
