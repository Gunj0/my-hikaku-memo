# 画面遷移・状態設計

## 1. 文書の目的

本書は、6 ステップ比較フローにおける状態、イベント、遷移条件、画面内制御を整理する。

## 2. 管理状態

### 2.1 グローバル状態

- currentStep: number。現在表示中のステップ番号。
- data: ComparisonData。比較フロー全体の入力状態。
- sessionUser: Session.user または null。現在ログイン中の利用者情報。
- activeMemo: ComparisonMemoSummary または null。現在編集中の保存済みメモ。公開状態を含む。
- savedMemos: ComparisonMemoSummary[]。保存済みメモ一覧。

### 2.2 ステップ内ローカル状態

- 比較ポイント追加欄の入力値
- 比較ポイント詳細の展開対象 ID
- 候補製品追加欄の入力値
- IME 変換中フラグ

## 3. ステップ一覧

| ステップ | 名称         | 主目的                         |
| -------- | ------------ | ------------------------------ |
| 1        | カテゴリ     | 比較対象カテゴリを定める       |
| 2        | 比較ポイント | 観点と重要度を定める           |
| 3        | 候補         | 比較対象製品を定める           |
| 4        | 評価入力     | 各製品の評価を入力する         |
| 5        | 集計結果     | 評価を集計して比較する         |
| 6        | 最終決定     | 購入製品を選択し理由を記録する |

## 4. イベント一覧

| イベント      | 内容                             |
| ------------- | -------------------------------- |
| Next          | 次のステップへ進む               |
| Prev          | 前のステップへ戻る               |
| StepClick     | 任意のステップへ直接移動する     |
| Reset         | 入力内容を初期化する             |
| UpdateData    | 比較データの一部を更新する       |
| SelectProduct | 最終決定製品を選択または解除する |
| SignIn        | Google ログインを開始する        |
| SignOut       | 現在のセッションを終了する       |
| SaveMemo      | 現在の比較内容を公開設定付きで保存する |
| LoadMemo      | 保存済みメモを読み込む           |
| DeleteMemo    | 保存済みメモを削除する           |

## 5. 遷移ルール

### 5.1 Next

- currentStep が最終ステップ未満であること。

### 5.2 Prev

- currentStep が 1 より大きいこと。

### 5.3 StepClick

- 任意のステップを選択できる。

### 5.4 Reset

- 利用者確認後、data を初期値に戻す。
- 保存済みメモ編集中であれば、最後に保存されたスナップショットへ戻す。
- 保存済みメモ編集中でなければ、currentStep を 1 に戻す。
- 初期比較ポイントの ID は再生成する。

## 6. ステップ別進行条件

| ステップ | 条件           |
| -------- | -------------- |
| 1        | 常に進行可能   |
| 2        | 常に進行可能   |
| 3        | 常に進行可能   |
| 4        | 常に進行可能   |
| 5        | 常に進行可能   |
| 6        | 次ステップなし |

## 8. 画面全体ライフサイクル

### 8.1 初期表示

- currentStep を 1 に設定する。
- data を初期 ComparisonData に設定する。
- 初期比較ポイントを複製し、各要素へ新規 ID を付与する。

### 8.2 入力更新

- 各ステップからの変更イベントは updateData 相当の処理で data に反映する。
- 状態更新は不変更新で行う。

### 8.3 描画切り替え

- currentStep の値に応じて表示コンポーネントを切り替える。
- 1 度に表示するステップは 1 つのみとする。

### 8.4 認証・保存済みメモ制御

- 未ログイン状態でも比較データ編集は継続できる。
- 保存または保存済みメモ一覧表示を要求したとき、未ログインであればログイン案内ダイアログを表示する。
- 保存ダイアログでは activeMemo の公開状態を初期値として表示する。
- 保存済みメモ読込時は、必要に応じて現在の編集中内容を置き換える確認を行う。
- 非公開メモの閲覧画面は所有者だけが到達できる。
- リセット時は未保存データを破棄するが、保存済みメモ編集中であれば activeMemo を維持したまま保存時点へ戻す。

## 9. 補助制御

### 9.1 完了ボタン制御

- currentStep が 6 のとき表示する。
- selectedProductId が null の場合は無効とする。
- 候補製品の削除が発生した場合は selectedProductId を null に戻す。
- 現行仕様では押下後の副作用は持たない。

### 9.2 リセット制御

- 確認ダイアログで承認された場合のみ実行する。

## 10. 現行仕様上の注意点

- ステップ 4 と 5 は入力不足でも進行できるため、比較情報が不完全なまま最終決定へ進むことがある。
- 候補製品や比較ポイントの削除時に score 整合性を自動修復しない。
- 最終決定画面は products が存在すれば表示可能であり、スコア入力の有無を必須とはしていない。
