# ドキュメント一覧

## 1. 目的

本ディレクトリは、「オレの比較メモ」の要件定義、設計情報、画面デザイン方針を整理するための文書群である。
README は導入と開発開始のための入口とし、本ディレクトリでは詳細仕様と設計判断を扱う。

## 2. 対象システム

- アプリ名: オレの比較メモ
- 対象: 購入候補製品を比較し、最終判断を整理するための Web アプリケーション
- 現行構成: Next.js App Router を用いたホーム、比較編集、保存済みメモ一覧、メモ閲覧ページ、および固定法務ページを持つ構成

## 4. 文書運用方針

- 本文書群は現行実装を説明することを基本とし、未実装の将来構想は原則記載しない。
- 要件変更が先行する場合は、要件文書を先に更新し、その後に設計文書を更新する。
- 画面表現の思想やトーンに関する変更は、画面デザイン方針を先に更新し、その後に画面仕様やコンポーネント設計へ反映する。
- 画面遷移条件、入力制約、スコア算出ルールは特に乖離しやすいため、変更時は必ず関連文書を同時更新する。

## 5. 文書の前提

- 本アプリは Google ログインを任意機能として持つ。
- ログインしていない利用者でも比較フローの閲覧と入力は行える。
- 保存済みメモの作成、読込、削除は Google ログイン後に利用できる。
- 保存済みメモは Cloudflare D1 に永続化される。
- 比較フロー自体は /edit の 1 画面内で完結する構成である。
