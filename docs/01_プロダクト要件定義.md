# プロダクト要件定義

## 1. 文書の目的

本書は、「オレの比較メモ」が何を解決するプロダクトであり、どの利用者に対してどこまでの機能を提供するかを定義する。

## 2. プロダクト概要

「オレの比較メモ」は、購入候補の製品を複数比較し、比較条件の整理から最終決定までを一連のステップで支援するアプリケーションである。
利用者は、カテゴリ選択、比較ポイント整理、候補製品登録、評価入力、最終決定という流れで判断材料を明文化できる。
また、Google ログインを行うことで複数の比較メモを保存し、あとから読み直して再開できる。

## 3. 背景と課題

製品購入時には、複数候補を並べて比較したい一方で、比較軸や重視度が曖昧なまま判断してしまうことが多い。
その結果、次のような課題が生じる。

- 比較軸が途中で変わる
- 何を重視していたかが曖昧になる
- 候補ごとの長所短所を整理しきれない
- 最後に感覚で決めてしまい、判断理由が残らない

本アプリは、比較の観点と評価結果を一画面のフローで整理し、判断の一貫性を高めることを目的とする。

## 4. 想定ユーザー

### 4.1 主要ユーザー

- 家電、ガジェット、日用品などの購入前に比較検討したい個人利用者
- 比較に時間をかけたいが、表計算ソフトほど重い運用は避けたい利用者
- 判断理由を短いメモとして残したい利用者

### 4.2 利用シーン

- スマートフォンやノート PC の買い替え検討
- イヤホン、カメラ、モニターなどの比較検討
- 家族や同居人と購入候補を整理する前段のメモ作成

## 5. 提供価値

- 比較ポイントを自分で選び、重要度を設定できる
- 候補製品を複数登録し、各ポイントごとに評価を付けられる
- 最終的に選んだ製品と決定理由を記録できる
- 比較途中の内容を保存し、複数の比較メモを再利用できる
- ログインしなくても比較を試せるため、使い始めの負荷が低い

## 6. プロダクトの対象範囲

本アプリの対象範囲は次の通りとする。

### 6.1 入力支援

- プリセットカテゴリの提示
- 任意カテゴリの自由入力
- 比較ポイントの初期値提示と追加・削除
- 候補製品の追加・削除
- 製品ごとの評価点とメモ入力
- 最終決定製品の選択と決定理由入力

### 6.2 比較支援

- 重視ポイントの抽出
- 重要度を用いた加重集計
- 製品ごとの合計点、比率、順位表示
- 集計結果を踏まえた最終決定支援

### 6.3 進行支援

- 5 ステップの進捗表示
- 前後移動
- ステップ指定の直接移動
- 全入力内容のリセット

### 6.4 アカウント・保存支援

- Google ログイン
- ログアウト
- 比較メモタイトルを指定した保存
- 保存済みメモごとの公開・非公開設定
- 保存済みメモ一覧表示
- 保存済みメモの読込
- 保存済みメモの上書き保存
- 保存済みメモの削除
- 公開された保存済みメモの閲覧

## 7. 対象外

現時点で本アプリの対象外とする事項は次の通りである。

- 複数比較案件の管理
- 他ユーザーとの共同編集
- 外部サイトからの製品情報自動取得
- 価格や在庫のリアルタイム取得
- 最終決定内容の出力、印刷、エクスポート
- 完了操作後の永続的な確定処理

## 8. 利用の前提

- 利用者はログインしなくても比較作業を開始できる
- 未保存の入力データはページ内状態として扱われる
- 未保存状態のまま画面離脱やリロードを行った場合の保持は保証しない
- 保存済みメモの利用には Google ログインが必要である

## 9. 成功条件

本プロダクトは、利用者が次の状態に到達できたときに目的を果たしたとみなす。

- 比較対象カテゴリが定まっている
- 比較に使うポイントが明確になっている
- 候補製品が 2 件以上登録されている
- 比較ポイントに対する評価が入力されている
- 評価表の合計点を確認した上で最終候補を選べる
- 選択理由を文章として残せる
- 必要に応じて比較内容を保存し、後から再開できる

## 10. 用語定義

| 用語         | 意味                                                              |
| ------------ | ----------------------------------------------------------------- |
| カテゴリ     | 比較対象となる製品の種別                                          |
| 比較ポイント | 製品を比較する評価観点                                            |
| 重要度       | 比較ポイントごとの重み。「必須」「できれば」「どちらでも」の 3 段階 |
| 候補製品     | 比較対象として登録された製品                                      |
| 評価点       | 各候補製品に対して比較ポイントごとに付ける 1 から 5 の点数        |
| 集計結果     | 評価点に重要度を掛けて算出した合計値および順位                    |
