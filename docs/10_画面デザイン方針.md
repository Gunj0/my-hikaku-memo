# 画面デザイン方針

## 1. 文書の目的

本書は、「オレの比較メモ」の画面表現に関する方針を整理する。
色、タイポグラフィ、情報密度、インタラクション、ラベル表現の原則を定義し、各画面仕様やコンポーネント設計の判断基準とする。

## 2. デザインの基本方針

- 比較作業に集中しやすい、高密度で落ち着いたワークベンチのような見た目を目指す。
- 装飾を主役にせず、比較対象、評価、最終判断が視線の中心になる構成とする。
- 一覧性と操作効率を優先し、視覚的な変化は状態理解を補助する範囲に留める。

## 3. 配色方針

- ベースカラーは Tokyo Night を基調とした青紫系とする。
- 通常の操作要素、選択状態、フォーカス状態は青紫系で統一する。
- 保存成功、比較優位、決定済み状態などの成功表現のみ Neon Green を使う。
- 注意喚起や無効状態は、成功色と混同しない控えめなコントラストで表現する。

## 4. タイポグラフィ方針

- 全体は等幅フォントベースで統一する。
- IBM Plex Mono と JetBrains Mono を中心に構成する。
- ラベル、数値、補助情報も含めて、比較表や一覧で桁や情報ブロックがそろって見えることを重視する。
- 見出しだけを過度に装飾せず、本文や数値との整列感を優先する。

## 5. レイアウトと情報密度方針

- 情報密度を優先し、比較に必要な状態をできるだけ一画面内で把握できるようにする。
- 薄いボーダー、小さめの角丸、グリッド感のある背景で、作業領域の区切りを明確にする。
- カード、表、入力欄は余白を過剰に広げず、読みやすさを維持したうえで密度を保つ。
- モバイルでは密度を落としすぎず、情報量は維持したまま配置を縦方向に再構成する。

## 6. インタラクション方針

- ホバーや状態変化の応答は速めにし、入力に対する反応を明確にする。
- アニメーションは補助的なものに限定し、ダイアログ表示や状態切り替えも短く控えめにする。
- 色、枠線、リング、アイコンの変化を組み合わせて、現在状態と操作結果を即座に識別できるようにする。
- ステップ移動や保存操作では、演出よりも処理結果の理解しやすさを優先する。

## 7. ラベルとメタ情報の表現方針

- UI ラベルやメタ情報は控えめに記号化し、画面全体を比較ワークベンチのような印象に寄せる。
- 補助情報は主情報より一段弱い見た目にしつつ、必要なときに即座に読める視認性は保つ。
- 進捗、重視ポイント数、候補数、保存状態のような運転席情報は、常に短く高密度に表示する。

## 8. 適用範囲

- 本方針は画面仕様、共通 UI、各ステップコンポーネントの見た目判断に適用する。
- 個別画面の具体的な表示ルールは画面仕様設計に記載し、責務分担や実装境界はシステム設計およびコンポーネント責務設計に記載する。
