# 機能要件定義

## 1. 文書の目的

本書は、現行アプリが提供する機能、入力、表示、操作条件、画面遷移条件を定義する。

## 2. 画面全体要件

### 2.1 画面構成

比較編集画面は 1 画面内で次の 5 ステップを順に進行する。

1. カテゴリ
2. 比較ポイント
3. 候補
4. 評価入力
5. 最終決定

### 2.2 全体操作

- ヘッダーにアプリ名とリセット操作を表示する。
- ヘッダーに保存、保存済みメモ一覧、ログイン操作を表示する。
- 進捗インジケータで現在のステップを表示する。
- フッターに前へ戻る操作と次へ進む操作を表示する。
- すべてのステップへ、進捗インジケータから直接移動できる。
- リセット実行時は確認ダイアログを表示し、承認後に全入力内容を初期化する。
- 保存済みメモを編集中にリセットした場合は、最後に保存された状態へ戻す。

### 2.3 遷移制御

- 前へ戻る操作はステップ 1 以外で利用できる。
- 次へ進む操作は常に利用できる。
- ステップ 5 では「保存」ボタンを表示する。
- 保存ボタンは製品が選択されるまで無効とする。
- 保存ボタン押下時は既存の保存ダイアログを開き、未ログイン時はログイン案内ダイアログを経由する。
- ヘッダーのログイン操作押下時はログイン案内ダイアログを開き、ダイアログ内から Google ログインを開始できる。

## 3. ステップ 1: カテゴリ選択

### 3.1 目的

比較対象となる製品カテゴリを定義する。

### 3.2 入力要件

- プリセットカテゴリから 1 件選択できる。
- 任意のカテゴリ名を自由入力できる。
- 補足メモを任意入力できる。

### 3.3 表示要件

- プリセットカテゴリ一覧をボタン形式で表示する。
- カスタムカテゴリ入力欄を表示する。
- 任意メモ入力欄を表示する。

### 3.4 進行条件

- 現行仕様では常に次へ進める。

## 4. ステップ 2: 比較ポイント設定

### 4.1 目的

製品比較の観点を定義し、重視する観点に重要度を設定する。

### 4.2 入力要件

- 初期比較ポイント一覧を表示する。
- 比較ポイントを任意追加できる。
- 追加済み比較ポイントのポイント名を編集できる。
- 新規追加した比較ポイントは、初期状態で重要度「丸」、空メモとして追加する。
- 比較ポイントを削除できる。
- 各比較ポイントは常に評価対象とする。
- 各比較ポイントに対して重要度「二重丸」「丸」「三角」「ばつ」を設定できる。
- 各比較ポイントごとにメモを入力できる。
- 比較ポイント全体に対するメモを入力できる。

### 4.3 表示要件

- 比較ポイント件数を表示する。
- 各ポイントは重要度選択、ポイント名、メモ欄を常時表示する。
- 重要度選択はポイント名の左側に配置する。

### 4.4 進行条件

- 現行仕様では常に次へ進める。

## 5. ステップ 3: 候補製品管理

### 5.1 目的

比較対象となる候補製品を登録する。

### 5.2 入力要件

- 候補製品名を追加できる。
- 登録済み候補製品の候補名を編集できる。
- 登録済み候補製品を削除できる。
- 各候補製品に対して任意メモを入力できる。
- 候補製品全体に対するメモを入力できる。

### 5.3 表示要件

- 候補が 0 件の場合は空状態表示を出す。
- 候補がある場合は一覧表示し、各候補に連番を付与する。

### 5.4 進行条件

- 現行仕様では常に次へ進める。

## 6. ステップ 4: 評価入力

### 6.1 目的

各候補製品について、比較ポイントごとの評価を入力する。

### 6.2 入力要件

- 各候補製品と各比較ポイントの組み合わせごとに、評価点 1 から 5 を入力できる。
- 各組み合わせに対して任意メモを入力できる。
- 評価入力画面上で比較ポイント名と候補製品名を編集できる。

### 6.3 表示要件

- モバイルでは製品単位のカード表示とする。
- デスクトップでは比較表形式で表示する。
- 各比較ポイントの重要度を表示する。
- デスクトップ表の最下部に候補製品ごとの合計点を表示する。

### 6.4 制約

- 候補製品が 0 件、または比較ポイントが 0 件の場合は入力画面の代わりに案内文を表示する。
- 評価点未入力の組み合わせは 0 点として扱う。

### 6.5 進行条件

- 現行仕様では無条件で次へ進める。

## 7. ステップ 5: 最終決定

### 7.1 目的

評価結果を踏まえて、購入する製品を明示的に選択し、その理由を記録する。

### 7.2 入力要件

- 候補製品の中から 1 件を選択できる。
- 選択解除ができる。
- 決定理由や補足事項を自由入力できる。

### 7.3 表示要件

- 集計順に候補製品を表示する。
- 最上位候補を視覚的に強調する。
- 選択済み製品がある場合は購入決定領域を表示する。
- 製品選択後は次のステップ案内を表示する。

### 7.4 制約

- 候補製品が 0 件の場合は選択 UI の代わりに案内文を表示する。

### 7.5 完了条件

- 保存ボタンは候補製品が 1 件選択されている場合に有効とする。
- 保存ボタン押下時は保存ダイアログを開く。
- 候補製品の削除が発生した場合は selectedProductId をクリアし、再選択を必要とする。

## 9. 入力補助要件

- 日本語入力中に Enter で誤追加が発生しないよう、IME 変換中判定を行う。
- 比較ポイント追加と候補製品追加は Enter キーでも実行できる。

## 10. 例外・境界要件

- スコア未入力でも最終決定画面へ進める。
- 評価表の合計点は未入力項目を 0 点として表示する。
- リセット時にはカテゴリ、メモ、候補、評価、選択結果を初期化する。
- 保存済みメモ編集中のリセット時には、初期空状態ではなく保存済み状態へ戻す。

## 11. 認証・保存要件

- ログインしていない場合でも比較フローの閲覧と入力は行える。
- 未ログインで /edit?memoId=... にアクセスした場合は /edit に戻し、新規作成として扱う。
- ログインしていない状態で保存または保存済みメモ一覧を要求した場合は、ログイン案内ダイアログを表示する。
- Google ログイン後は保存済みメモの一覧取得ができる。
- アカウント初回作成時は、Google の表示名と画像を公開面へそのまま出さず、アプリ側で仮ユーザー名と仮アイコンを割り当てる。
- 公開メモ一覧および公開メモ詳細では、Google プロフィールではなくアプリ側プロフィールを表示する。
- アカウント設定画面（/settings）にはログアウト操作を表示する。
- アカウント設定画面では、ログイン中ユーザーが公開プロフィール用の表示ユーザー名と、URL 用のユーザーID（username）を編集できる。
- ユーザーID は初回ログイン時に自動採番し、以後ユーザーが変更できる。他ユーザーと重複する値および予約語は登録できない。
- 現行仕様ではアイコン変更は提供せず、アカウント作成時に割り当てたアイコンを継続利用する。
- 保存時にはメモタイトルと公開・非公開を入力できる。
- 既存メモを開いている場合は上書き保存と新規保存を選択できる。
- 保存済みメモ一覧では各メモに対して公開状態の確認、読込、削除を行える。
- 保存済みメモの読込時は、現在の編集中内容を置き換える確認を行う場合がある。
- 保存済みメモの編集 URL と memoId 付き再開は、ログイン中ユーザーに限定する。
- 保存済みメモの削除はログイン中ユーザーの所有メモに限定する。
- /edit ではグローバルヘッダーを表示しない。
- 非公開メモは所有者以外の公開一覧および閲覧画面に表示しない。
