# 画面仕様設計

## 1. 文書の目的

本書は、各ステップ画面の表示項目、入力項目、操作、表示条件、レスポンシブ差分を定義する。

## 2. 共通画面仕様

### 2.1 ヘッダー

- アプリ名を表示する。
- アプリ名の上に小さなメタラベルを表示できる。
- ログイン状態を表示する。
- ログイン中はアプリ側で保持する公開ユーザー名と仮アイコンを表示する。
- 保存ボタンを表示する。
- 保存済みメモ一覧ボタンを表示する。
- 未ログイン時はログインボタンを表示し、押下でログイン案内ダイアログを開く。
- リセットボタンを表示する。
- 進捗インジケータを表示する。
- 進行率、重視ポイント数、候補数、保存状態を高密度に表示する。
- /memos/new ではグローバルヘッダーを表示しない。

### 2.2 共通ダイアログ

- 未ログイン時に保存系操作を行った場合はログイン案内ダイアログを表示する。
- 保存時はメモタイトル入力と公開設定トグルを含むダイアログを表示する。
- 保存済みメモ一覧表示時は、公開状態表示、読込、削除操作を含む管理ダイアログを表示する。

### 2.3 マイメモ画面の追加表示

- 保存済みメモ一覧画面の上部に、公開ユーザー設定カードを表示する。
- 保存済みメモ一覧画面の上部に、ログアウトボタンを表示する。
- プロフィール設定カードには仮アイコン、現在のユーザー名、ユーザー名入力欄、保存ボタンを表示する。
- アイコン変更操作は表示しない。

### 2.4 メイン領域

- currentStep に応じたステップ画面を 1 つ表示する。
- デスクトップでは補助的なサイド情報領域を併設できる。
- 新規作成画面では新規作成専用キーの localStorage 自動保存内容がある場合に初期表示時から復元する。
- 未ログインで memoId 付き URL を開いた場合は /memos/new へ戻し、新規作成画面として表示する。
- 既存メモの編集画面では、ログイン中に限り memoId が一致する localStorage の自動保存内容がある場合に初期表示時から復元する。

### 2.5 フッター

- 戻るボタンを表示する。
- 現在ステップ番号と総ステップ数を表示する。
- 次へ進む、または保存ボタンを表示する。
- 戻るボタンと次へボタン押下時は、新規作成中は新規作成専用キー、既存メモ編集中は memoId キーで遷移先の状態を localStorage へ即時保存する。

## 3. ステップ 1: カテゴリ

### 3.1 表示項目

- 見出し
- 説明文
- プリセットカテゴリボタン群
- カスタムカテゴリ入力欄
- カテゴリメモ入力欄

### 3.2 操作

- プリセットカテゴリボタン押下でカテゴリを設定する。
- カスタムカテゴリ入力でカテゴリを設定する。
- 補助ボタン押下で入力中カテゴリを確定する。
- メモ欄へ自由記述する。

### 3.3 表示ルール

- 選択中のプリセットカテゴリは強調表示する。
- カスタムカテゴリが選択されている場合のみ入力欄に値を表示する。

## 4. ステップ 2: 比較ポイント

### 4.1 表示項目

- 見出し
- 説明文
- ポイント件数
- 比較ポイント一覧
- 新規ポイント追加欄
- 全体メモ入力欄

### 4.2 操作

- 重要度選択の切り替え
- 比較ポイントのドラッグアンドドロップによる並び替え
- 個別メモ入力
- 比較ポイント追加
- 比較ポイント削除

### 4.3 表示ルール

- すべての比較ポイントを評価対象として扱う。
- 重要度は「二重丸」「丸」「三角」「ばつ」の 4 段階から選択する。
- 重要度選択はポイント名の左側に表示する。
- ポイント名、重要度、個別メモ欄は常時表示する。

## 5. ステップ 3: 候補

### 5.1 表示項目

- 見出し
- 説明文
- 候補追加欄
- 空状態表示または候補一覧
- 全体メモ入力欄

### 5.2 操作

- 候補製品追加
- 候補製品のドラッグアンドドロップによる並び替え
- 候補製品削除
- 候補ごとのメモ入力
- 全体メモ入力

### 5.3 表示ルール

- 候補がない場合はアイコン付き空状態を表示する。
- 候補がある場合はカード形式で一覧表示する。
- 一覧には表示順の連番を表示する。

## 6. ステップ 4: 評価入力

### 6.1 表示項目

- 見出し
- 説明文
- 条件未達時の案内文、または評価入力 UI

### 6.2 モバイル表示

- 製品単位のカードを表示する。
- カード内に各比較ポイント名、重要度、星入力、メモ欄を表示する。

### 6.3 デスクトップ表示

- 比較ポイントを行、候補製品を列とする表を表示する。
- 各セルに星入力とメモ欄を表示する。
- 表の最下部に候補製品ごとの合計点を表示する。

### 6.4 操作

- 比較ポイント行のドラッグアンドドロップによる並び替え
- 候補製品列のドラッグアンドドロップによる並び替え
- 星アイコン押下で評価点を設定する。
- メモ欄入力で対象組み合わせのメモを設定する。

### 6.5 表示ルール

- 対象は比較ポイント全件とする。
- 未入力点数は 0 点扱いとし、未選択状態の星表示とする。

## 7. ステップ 5: 最終決定

### 7.1 表示項目

- 見出し
- 説明文
- 条件未達時の案内文、または候補選択 UI
- 選択済み製品の決定表示領域
- 決定理由入力欄
- 次のステップ案内

### 7.2 操作

- 候補製品の選択
- 選択解除
- 決定理由メモ入力

### 7.3 表示ルール

- 候補は集計順に並べる。
- 最上位候補は順位表示を Neon Green で強調する。
- 選択中候補は枠線とリングで明示する。
- 選択済みのときは上部に決定済み表示を出し、成功状態として Neon Green を使う。

## 9. 進捗インジケータ仕様

### 9.1 モバイル

- 横スクロール可能なボタン列とする。
- 完了済み、現在、未到達の各状態を見た目で区別する。

### 9.2 デスクトップ

- 全幅のステップ列とし、ステップ間連結線を表示する。
- すべてのステップをクリック可能とする。

## 10. ボタン活性仕様

- フッターの戻るボタンは currentStep > 1 のとき有効とする。
- フッターの次へボタンはステップ 1 から 4 で常に有効とする。
- フッターの保存ボタンは selectedProductId が存在するとき有効とし、押下時は保存ダイアログを開く。
- ヘッダーの保存ボタンは常に表示し、未ログイン時は案内ダイアログを経由する。
- ヘッダーの保存済みメモボタンは常に表示し、未ログイン時は案内ダイアログを経由する。
- ヘッダーのリセットボタンは常に活性とする。
- 新規作成中の内容は新規作成専用キーで、保存済みメモ編集中の内容は memoId キーで 10 秒ごとに localStorage へ自動保存する。
- 候補製品の削除が発生した場合は selectedProductId を解除し、保存ボタンを無効に戻す。
- 保存済みメモ編集中のリセットは、保存済み状態へ戻す。
